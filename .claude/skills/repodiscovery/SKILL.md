# repodiscovery

Quickly orient in an unfamiliar repo: layout, conventions, entry points, config.

## Steps

1. Map directory structure and key modules.
2. Find entry points (server, CLI, build).
3. Read AGENTS.md / config for conventions.
4. Report a concise orientation map and where to start.

## Constraints

- Verify by execution where possible; never report working on source inspection alone.
- Cite file:line evidence for every finding.
- Report DONE/PASS only when the live behavior matches the intended purpose.

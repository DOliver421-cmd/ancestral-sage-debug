Platform Migration Blueprint

Approved by Executive Meeting · NAM Oshun Edutainment LLC · One codebase, two focused doors

The Decision

www.morehelp.center is the single hub for support, billing, account administration, and the SOUP Poetry / creative community. www.wai-institute.org becomes the focused institution site: electrical education, professional education, and media strategy — no distractions, no mixed messaging, clean SEO.

How This Is Possible

The platform is one codebase serving both domains. Every feature named below already runs on morehelp.center today. Transferring a feature means changing which domain shows it, where its links point, and how it is framed — not rebuilding it. No new backend, no data migration, no second database.

One honest constraint: sign-in state is per-domain. A member signed into morehelp.center will sign in again on wai-institute.org. Both doors share the same account database — this is normal for separate domains.

Execution Plan

  1. Domain-aware front door — replace the wai-institute.org redirect in frontend/src/App.js with a focused WAI landing rendered for that hostname. Same build, same deployment.
  2. Domain-aware navigation — the sidebar filters by hostname; support/billing/creative items become outbound links to www.morehelp.center.
  3. DNS & CORS — both domains point at the same host; verify CORS allows both origins.
  4. Footer & help routing — WAI footer gains a permanent Help & Support → morehelp.center link; support widgets link out instead of opening in-app.
  5. Content audit — handbooks/FAQs rebranded as the MORE Knowledge Base; add missing articles (browser requirements, certificate delivery, refunds).
  6. SEO isolation — WAI owns NFPA 70 / NEC 2023 / electrical safety terms; MORE owns support + creative + community terms.

What This Does NOT Require

  • No new backend, no data migration, no new database
  • No rebuilding of support, billing, or creative features — they run on MORE today
  • No changes to payment processing or the account system
